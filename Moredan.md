# Moredan Product Characteristics

Moredan is a single-page web application that provides a comprehensive yearly calendar view.

## Core Features
- **Yearly Calendar View:** Displays every day of every month of a single year on one page.
- **Zero Scroll Design:** The entire calendar and UI are designed to fit within the viewport without horizontal or vertical scrolling.
- **Event Management:**
  - Users can add events with a name, start time, end time, and category.
  - Events are visually represented in the yearly calendar.
- **Category System:**
  - Users can maintain a list of categories.
  - Each category has an associated color.
  - Events are displayed in the calendar using their category's color.
- **Filtering:**
  - Users can toggle the visibility of events based on their category.

## Technical Goals
- High visual impact and polished aesthetics.
- Responsive design that maintains the "no-scroll" constraint across common desktop resolutions.
