Grid Alignment PoC — Round 2

Single-day event on day 20 (yellow highlight). Check edges at 100 %, 110 %, 125 %, 150 % zoom.

Round 1 finding: Approach A did not spill → two-grid concept is not inherently broken.
Approach B (position:relative) was broken because it took up flow space, pushing day 31 off screen.
This round tests Approach C: position:absolute direct child, which uses the parent grid area as its containing block.

Approach A — Two grids (current app implementation)

Overlay div with its own display:grid / same column template, position:absolute over the month row. Round 1 showed no spill in the PoC. Re-testing here as baseline.

JAN

Approach C — Absolutely-positioned direct grid child (no overlay grid)

Event bar is a direct child of .month-row with position:absolute + explicit grid-column / grid-row. Per CSS Grid spec, the containing block becomes the grid area at those lines — the same lines as the day cell in the same grid. No second grid, no independent rounding.
